Replacing a mixing matrix by a flexible nonlinear function makes the model more expressive, but also gives it more ways to explain the same observations. Undoing a bend does not fix the source scale撤销弯曲，不代表源尺度也确定了

  1. Let $s_1,s_2$ be independent uniform variables on $(0,1)$. Observe $x_1=s_1$ and $x_2=s_2+s_1^2$. There are two source coordinates and two measured coordinates; the square makes this a nonlinear mixing function.
  2. If that function is known, undo it with $s_1=x_1$ and $s_2=x_2-x_1^2$. For $(x_1,x_2)=(1/2,1/2)$ this gives $(s_1,s_2)=(1/2,1/4)$.
  3. Now report $y_1=s_1$ and $y_2=s_2^3$ instead. The outputs are still independent, since each depends on only one independent source. Cubing is invertible on $(0,1)$, but the same sample is now $(1/2,1/64)$. Independence did not fix its numerical scale.
  1. 设 $s_1,s_2$ 相互独立，均匀分布于 $(0,1)$。观测为 $x_1=s_1$、$x_2=s_2+s_1^2$。源与观测各有两个坐标；平方项使混合函数成为非线性的。
  2. 如果已知这个函数，就用 $s_1=x_1$、$s_2=x_2-x_1^2$ 反解。$(x_1,x_2)=(1/2,1/2)$ 对应 $(s_1,s_2)=(1/2,1/4)$。
  3. 现在改为输出 $y_1=s_1$、$y_2=s_2^3$。每个输出只依赖一个独立源，所以输出仍然独立。立方在 $(0,1)$ 上可逆，但同一样本变成了 $(1/2,1/64)$。独立性没有固定其数值尺度。

This illustrates the allowed componentwise ambiguity, not the full impossibility proof. The main text shows a stronger problem: unrestricted nonlinear alternatives can mix several sources while preserving independence. Successful theory must restrict the competing models too.

这个例子说明允许存在的逐分量歧义，并不是完整的不可辨识性证明。正文展示更强的问题：不受限制的非线性替代解可以混合多个源，同时保持独立。成功的理论也必须约束这些竞争模型。

Nonlinear mixing非线性混合

The linear model $\bx = \bA\bs$ is an idealization. Sensors saturate, images are formed through occlusion, shading and perspective, and the factors that generate natural data are rarely added together with fixed weights. The natural generalization keeps independent sources but replaces the matrix by a function:

线性模型 $\bx = \bA\bs$ 是一种理想化。传感器会饱和；图像经由遮挡、明暗与透视而形成；生成自然数据的各种因素，也很少以固定的权重简单相加。最自然的推广是保留相互独立的源，而把矩阵换成一个函数：

$$\bx = \mathbf{f}(\bs), \qquad p_{\bs}(\bs) = \prod_{i=1}^n p_i(s_i),$$

where $\mathbf{f}\colon \R^n \to \R^n$ is an unknown invertible function, the mixing function. We assume as many observations as sources and, where needed, that $\mathbf f$ and $\mathbf f^{-1}$ are smooth. Nonlinear ICA seeks a function $\mathbf g$ such that the components of $\by = \mathbf g(\bx)$ recover the sources. With $\mathbf f(\bs) = \bA\bs$ this is ordinary ICA, which showed to be solvable up to scaling and permutation whenever at most one source is Gaussian.

其中 $\mathbf{f}\colon \R^n \to \R^n$ 是未知的可逆函数，称为混合函数。我们假设观测维数与源的个数相同，并在需要时假设 $\mathbf f$ 与 $\mathbf f^{-1}$ 都是光滑的。非线性 ICA 要找一个函数 $\mathbf g$，使 $\by = \mathbf g(\bx)$ 的各分量恢复出源。当 $\mathbf f(\bs) = \bA\bs$ 时，这就是普通的 ICA；已经证明，只要至多一个源是高斯的，它就能在尺度与置换的意义下求解。

Some ambiguity is unavoidable, and it is larger than in the linear case. Let $\pi$ be a permutation of $\{1, \dots, n\}$ and $h_1, \dots, h_n$ invertible scalar functions, and set $\tilde s_i = h_i(s_{\pi(i)})$. Each $\tilde s_i$ is a function of a different source, so the $\tilde s_i$ are again independent. Write $\mathbf h$ for the invertible map $\bs \mapsto \tilde\bs$; then $\bx = \mathbf f(\bs) = \tilde{\mathbf f}(\tilde\bs)$ with $\tilde{\mathbf f} = \mathbf f \circ \mathbf h^{-1}$. The data cannot tell $(\mathbf f, \bs)$ from $(\tilde{\mathbf f}, \tilde\bs)$, so the best one can hope for is the following.

某种不确定性是无法避免的，而且比线性情形更大。设 $\pi$ 是 $\{1, \dots, n\}$ 的一个置换，$h_1, \dots, h_n$ 是可逆的标量函数，令 $\tilde s_i = h_i(s_{\pi(i)})$。每个 $\tilde s_i$ 只是某一个源的函数，且所涉及的源各不相同，因此 $\tilde s_i$ 仍然相互独立。记 $\mathbf h$ 为可逆映射 $\bs \mapsto \tilde\bs$，则 $\bx = \mathbf f(\bs) = \tilde{\mathbf f}(\tilde\bs)$，其中 $\tilde{\mathbf f} = \mathbf f \circ \mathbf h^{-1}$。数据无法区分 $(\mathbf f, \bs)$ 与 $(\tilde{\mathbf f}, \tilde\bs)$，所以最理想的结果也只能是下面这种意义下的分离。

A function $\mathbf g$ separates the sources if $g_i(\bx)=\phi_i(s_{\pi(i)})$ for a permutation $\pi$ and invertible scalar functions $\phi_i$. Identifiability within a specified model class means that any two admissible representations giving the same observable distribution differ only by these transformations. Competing representations must obey all restrictions defining the class, not merely independence. With auxiliary variables below, the observable law is that of $(\bx,\bu)$ and the source assumption is conditional independence given $\bu$.

若存在置换 $\pi$ 与可逆标量函数 $\phi_i$，使 $g_i(\bx)=\phi_i(s_{\pi(i)})$，则称 $\mathbf g$ 分离了源。在指定模型类中的可辨识性，是指任何产生相同可观测分布的两种允许表示，只能相差这些变换。替代表示必须满足定义该模型类的全部限制，而不只是独立性。在下文的辅助变量模型中，可观测分布是 $(\bx,\bu)$ 的联合分布，源的假设则是给定 $\bu$ 的条件独立性。

Two features of this definition matter later. First, the marginal distributions of the sources carry no information. With $F_i$ the cumulative distribution function (CDF) of $s_i$ and $\Phi$ the standard Gaussian CDF, the map $h_i = \Phi^{-1}\circ F_i$ turns any source with a continuous, strictly increasing CDF into a standard Gaussian variable (). Non-Gaussianity of the marginals, the basis of linear ICA, is therefore useless here. Second, since one may as well assume Gaussian sources, the rotational ambiguity of Gaussian vectors from is never far away. The next section turns this observation into a theorem.

这个定义有两点后面会用到。第一，源的边缘分布不携带任何信息。记 $F_i$ 为 $s_i$ 的累积分布函数（CDF），$\Phi$ 为标准高斯分布的 CDF，则映射 $h_i = \Phi^{-1}\circ F_i$ 能把任何 CDF 连续且严格递增的源变成标准高斯变量（）。线性 ICA 赖以成立的边缘非高斯性，在这里毫无用处。第二，既然不妨假设源都是高斯的，中高斯向量的旋转不确定性便近在眼前。下一节把这一观察变成定理。

Independence is not enough仅有独立性是不够的

The basic tool is the probability integral transform: if a random variable $u$ has a continuous CDF $F$, then $F(u)$ is uniform on $(0, 1)$. Applying it one coordinate at a time, each time conditionally on the coordinates already processed, turns a vector with continuous conditional distributions into one with independent uniform components. Write $F_{k\mid 1:k-1}(\cdot \mid x_1, \dots, x_{k-1})$ for the conditional CDF of $x_k$ given $x_1, \dots, x_{k-1}$, and define

基本工具是概率积分变换：若随机变量 $u$ 的 CDF $F$ 是连续的，则 $F(u)$ 在 $(0, 1)$ 上均匀分布。逐个坐标地使用这一变换，每次都以已经处理过的坐标为条件，在条件分布连续的假设下，就能把随机向量变成分量独立且均匀分布的向量。记 $F_{k\mid 1:k-1}(\cdot \mid x_1, \dots, x_{k-1})$ 为给定 $x_1, \dots, x_{k-1}$ 时 $x_k$ 的条件 CDF，定义

$$g_1(\bx) = F_1(x_1), \qquad g_k(\bx) = F_{k\mid 1:k-1}(x_k \mid x_1, \dots, x_{k-1}), \quad k = 2, \dots, n,$$

where $F_1$ is the CDF of $x_1$. This triangular map is often called the Darmois construction; Hyvärinen and Pajunen (1999) used it to show that nonlinear ICA has far too many solutions under these continuous-distribution assumptions. It is a nonlinear counterpart of Gram–Schmidt orthogonalization: the $k$-th output keeps only what $x_k$ adds to the coordinates before it, and for a Gaussian vector the construction reduces to Cholesky whitening followed by $\Phi$ ().

其中 $F_1$ 是 $x_1$ 的 CDF。这个三角形映射通常称为 Darmois 构造；Hyvärinen 与 Pajunen（1999）用它证明了在这些连续分布假设下，非线性 ICA 的解多得过了头。它相当于 Gram–Schmidt 正交化的非线性版本：第 $k$ 个输出只保留 $x_k$ 相对于前面各坐标新增的部分；对高斯向量而言，这一构造就退化为 Cholesky 白化再接上 $\Phi$（）。

(a) Let $\bx$ be a random vector in $\R^n$ whose density is positive on an open convex set $\mathcal{X}$ and zero outside it, with each prefix marginal density finite and positive at every point of its projected support. Then the map $\mathbf g$ of is a bijection from $\mathcal X$ onto $(0,1)^n$, and $\by = \mathbf g(\bx)$ is uniformly distributed on $(0,1)^n$. In particular $y_1, \dots, y_n$ are independent.

(a) 设随机向量 $\bx \in \R^n$ 的密度在某个开凸集 $\mathcal{X}$ 上处处为正、在其外为零，并且每个前缀边缘密度在其投影支撑的每一点都有限且为正。则 定义的映射 $\mathbf g$ 是从 $\mathcal X$ 到 $(0,1)^n$ 的双射，且 $\by = \mathbf g(\bx)$ 在 $(0,1)^n$ 上均匀分布。特别地，$y_1, \dots, y_n$ 相互独立。

(b) Let $n \ge 2$ and let $s_1, \dots, s_n$ be independent, each with a CDF that is continuous and strictly increasing on an open interval carrying all of its probability. Then there is an invertible map $\mathbf h$ such that $\mathbf h(\bs)$ has the same distribution as $\bs$, so that its components are independent, while its first component is strictly increasing in $s_1$ and strictly decreasing in $s_2$. Consequently, for every invertible mixing function $\mathbf f$, the map $\mathbf g = \mathbf h \circ \mathbf f^{-1}$ produces independent outputs without separating the sources, and nonlinear ICA is not identifiable.

(b) 设 $n \ge 2$，$s_1, \dots, s_n$ 相互独立，且每个 $s_i$ 的 CDF 在某个承载其全部概率的开区间上连续且严格递增。则存在可逆映射 $\mathbf h$，使 $\mathbf h(\bs)$ 与 $\bs$ 同分布（因而其分量相互独立），而它的第一个分量关于 $s_1$ 严格递增、关于 $s_2$ 严格递减。于是，对任何可逆混合函数 $\mathbf f$，映射 $\mathbf g = \mathbf h \circ \mathbf f^{-1}$ 的输出相互独立，却并没有分离源：非线性 ICA 不可辨识。

(a) Let $\mathcal X_k$ be the projection of $\mathcal X$ onto the first $k$ coordinates, an open convex set, and let $p_{1:k}$ be the marginal density of $(x_1, \dots, x_k)$; it is positive on $\mathcal X_k$, because it integrates the density over a nonempty open set of the remaining coordinates. For fixed $(x_1, \dots, x_{k-1}) \in \mathcal X_{k-1}$, the values of $x_k$ with $(x_1, \dots, x_k) \in \mathcal X_k$ form an open interval, on which the conditional density $p_{1:k}/p_{1:k-1}$ is positive. So the conditional CDF of $x_k$, as a function of $x_k$, increases continuously and strictly from 0 to 1 across this interval, and every $y_k \in (0,1)$ has exactly one preimage $x_k$. Solving $\by = \mathbf g(\bx)$ for $x_1, x_2, \dots, x_n$ in turn shows that $\mathbf g$ is a bijection from $\mathcal X$ onto $(0,1)^n$.

(a) 记 $\mathcal X_k$ 为 $\mathcal X$ 在前 $k$ 个坐标上的投影，它是开凸集；记 $p_{1:k}$ 为 $(x_1, \dots, x_k)$ 的边缘密度。由于它是把密度在其余坐标的一个非空开集上积分得到的，所以在 $\mathcal X_k$ 上为正。固定 $(x_1, \dots, x_{k-1}) \in \mathcal X_{k-1}$，使 $(x_1, \dots, x_k) \in \mathcal X_k$ 的 $x_k$ 构成一个开区间，条件密度 $p_{1:k}/p_{1:k-1}$ 在这个区间上为正。因此 $x_k$ 的条件 CDF 作为 $x_k$ 的函数，在该区间上从 0 连续且严格地增加到 1，每个 $y_k \in (0,1)$ 恰有一个原像 $x_k$。依次对 $x_1, x_2, \dots, x_n$ 求解 $\by = \mathbf g(\bx)$，即知 $\mathbf g$ 是从 $\mathcal X$ 到 $(0,1)^n$ 的双射。

Now fix $k$ and condition on $(x_1, \dots, x_{k-1})$. Given these values, $x_k$ has a continuous distribution with CDF $F_{k\mid 1:k-1}(\cdot \mid x_1, \dots, x_{k-1})$, so by the probability integral transform $y_k$ is uniform on $(0,1)$ whatever the conditioning values are. Its conditional distribution does not depend on $(x_1, \dots, x_{k-1})$, so $y_k$ is independent of $(x_1, \dots, x_{k-1})$, and hence of $(y_1, \dots, y_{k-1})$, which is a function of these coordinates. Therefore, for all $c_1, \dots, c_k \in (0,1)$,

再固定 $k$，以 $(x_1, \dots, x_{k-1})$ 为条件。给定这些值，$x_k$ 服从 CDF 为 $F_{k\mid 1:k-1}(\cdot \mid x_1, \dots, x_{k-1})$ 的连续分布，由概率积分变换，无论条件取什么值，$y_k$ 都在 $(0,1)$ 上均匀分布。它的条件分布与 $(x_1, \dots, x_{k-1})$ 无关，所以 $y_k$ 与 $(x_1, \dots, x_{k-1})$ 独立，从而与作为这些坐标之函数的 $(y_1, \dots, y_{k-1})$ 独立。于是对任意 $c_1, \dots, c_k \in (0,1)$，

$$P(y_1 \le c_1, \dots, y_k \le c_k) = c_k\,P(y_1 \le c_1, \dots, y_{k-1} \le c_{k-1}),$$

and by induction the joint CDF of $\by$ is $c_1 c_2 \cdots c_n$, that of the uniform distribution on $(0,1)^n$.

归纳可得 $\by$ 的联合 CDF 为 $c_1 c_2 \cdots c_n$，即 $(0,1)^n$ 上均匀分布的 CDF。

(b) Let $F_i$ be the CDF of $s_i$. By the probability integral transform, $z_i = \Phi^{-1}(F_i(s_i))$ is standard Gaussian, so $\bz = (z_1, \dots, z_n)^\top \sim \Ncal(\bzero, \bI)$. Let $\bQ$ rotate the first two coordinates by the angle $\pi/4$ and leave the others unchanged; then $\bQ\bz \sim \Ncal(\bzero, \bI)$ as well (). Set $h_i(\bs) = F_i^{-1}\bigl(\Phi((\bQ\bz)_i)\bigr)$, with $F_i^{-1}$ the inverse of $F_i$ on its interval. The components of $\mathbf h(\bs)$ are independent because those of $\bQ\bz$ are, and the $i$-th has CDF $F_i$, so $\mathbf h(\bs)$ has the distribution of $\bs$. The map $\mathbf h$ is a composition of bijections, hence invertible. Finally $(\bQ\bz)_1 = (z_1 - z_2)/\sqrt 2$, so $h_1(\bs) = F_1^{-1}\bigl(\Phi((\bQ\bz)_1)\bigr)$ is strictly increasing in $z_1$, hence in $s_1$, and strictly decreasing in $z_2$, hence in $s_2$. Since $\mathbf g(\bx) = \mathbf h(\bs)$, the outputs of $\mathbf g$ are independent, yet $g_1(\bx)$ is not a function of any single source.

(b) 记 $F_i$ 为 $s_i$ 的 CDF。由概率积分变换，$z_i = \Phi^{-1}(F_i(s_i))$ 服从标准高斯分布，所以 $\bz = (z_1, \dots, z_n)^\top \sim \Ncal(\bzero, \bI)$。令 $\bQ$ 把前两个坐标旋转 $\pi/4$ 角、其余坐标不变，则同样有 $\bQ\bz \sim \Ncal(\bzero, \bI)$（）。令 $h_i(\bs) = F_i^{-1}\bigl(\Phi((\bQ\bz)_i)\bigr)$，其中 $F_i^{-1}$ 是 $F_i$ 在其区间上的反函数。由于 $\bQ\bz$ 的分量相互独立，$\mathbf h(\bs)$ 的分量也相互独立，且第 $i$ 个分量的 CDF 为 $F_i$，所以 $\mathbf h(\bs)$ 与 $\bs$ 同分布。$\mathbf h$ 是若干双射的复合，因而可逆。最后，$(\bQ\bz)_1 = (z_1 - z_2)/\sqrt 2$，所以 $h_1(\bs) = F_1^{-1}\bigl(\Phi((\bQ\bz)_1)\bigr)$ 关于 $z_1$ 严格递增，从而关于 $s_1$ 严格递增；关于 $z_2$ 严格递减，从而关于 $s_2$ 严格递减。由于 $\mathbf g(\bx) = \mathbf h(\bs)$，$\mathbf g$ 的输出相互独立，但 $g_1(\bx)$ 不是任何单个源的函数。

Part (a) applies to any vector satisfying its density and support assumptions, whether or not it came from a source model. It does not cover arbitrary discrete or singular distributions. Independent outputs therefore cannot certify recovery of physical sources, even when the true mixing happens to be linear.

第一部分适用于满足其密度与支持集条件的任意向量，无论它是否来自源模型；它不涵盖任意离散或奇异分布。因此，即使真实混合恰好是线性的，输出独立也不能证明恢复了物理源。

Let $s_1, s_2$ be independent and uniform on $(0,1)$, and observe the linear mixture $x_1 = s_1$, $x_2 = s_1 + s_2$, which linear ICA would separate. Apply the Darmois construction taking $x_2$ first. The sum of two independent uniforms has the triangular CDF $F(c) = c^2/2$ for $0 \le c \le 1$ and $F(c) = 1 - (2 - c)^2/2$ for $1 \le c \le 2$, and given $x_2 = c$, the variable $x_1$ is uniform on $[\max(0, c-1), \min(1, c)]$. Hence

设 $s_1, s_2$ 相互独立，都在 $(0,1)$ 上均匀分布，观测到线性混合 $x_1 = s_1$，$x_2 = s_1 + s_2$；线性 ICA 可以把它分开。现在先取 $x_2$、再取 $x_1$ 做 Darmois 构造。两个独立均匀变量之和服从三角分布，其 CDF 为：$0 \le c \le 1$ 时 $F(c) = c^2/2$，$1 \le c \le 2$ 时 $F(c) = 1 - (2 - c)^2/2$；而给定 $x_2 = c$ 时，$x_1$ 在 $[\max(0, c-1), \min(1, c)]$ 上均匀分布。因此

$$y_1 = F(x_2), \qquad y_2 = \frac{x_1 - \max(0,\, x_2 - 1)}{\min(1,\, x_2) - \max(0,\, x_2 - 1)}.$$

The support of $\bx$ is an open parallelogram, so by part (a) of , with the coordinates taken in the order $x_2, x_1$, the outputs $y_1$ and $y_2$ are independent and uniform. Yet each depends on both sources.

$\bx$ 的支撑集是一个开平行四边形，所以按 $x_2, x_1$ 的坐标次序应用的 (a) 部分，输出 $y_1$ 与 $y_2$ 相互独立且均匀分布。但每个输出都同时依赖两个源。

The following script checks both claims on $10^5$ samples.

下面的脚本在 $10^5$ 个样本上检验这两点。

import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
T = 100_000
s1 = rng.uniform(0, 1, T)                 # two independent sources
s2 = rng.uniform(0, 1, T)
x1, x2 = s1, s1 + s2                      # a linear mixture

# Darmois construction, taking x2 first and x1 second
y1 = np.where(x2 <= 1, x2**2 / 2, 1 - (2 - x2)**2 / 2)   # CDF of x2 (triangular)
lo, hi = np.maximum(0, x2 - 1), np.minimum(1, x2)         # given x2, x1 ~ U(lo, hi)

Restricting the mixing function限制混合函数

留下了两条出路：限制混合函数的类别，或者赋予源比独立性更多的结构。最早的限制是 Taleb 与 Jutten（1999）提出的后非线性（post-nonlinear, PNL）模型：线性混合在每个传感器中再经过一个可逆的非线性变换，

$$x_i = f_i\Bigl(\sum_{j=1}^n a_{ij}\,s_j\Bigr), \qquad i = 1, \dots, n,$$

The PNL model escapes because its separating structure, $n$ scalar functions and one matrix, is too rigid to reproduce maps that act jointly on several coordinates, such as the Darmois map or the spiral of . The price is generality, since the processes behind images or neural recordings are neither post-nonlinear nor conformal. The rest of the chapter keeps $\mathbf f$ flexible within the stated regularity class and adds structure to the sources instead.

PNL 模型 之所以能躲开，是因为它的分离结构（$n$ 个标量函数加一个矩阵）过于刚性，无法复现同时作用于多个坐标的映射，例如 Darmois 映射或 中的螺旋映射。把 $\mathbf f$ 限制为共形映射也有类似效果：Hyvärinen 与 Pajunen（1999）给出了二维情形的唯一性结果，Buchholz、Besserve 与 Schölkopf（2022）把这类结果推广到更高维，两者都是在一个由简单变换构成的小群的意义下唯一。代价是一般性：图像或神经记录背后的生成过程既不是后非线性的，也不是共形的。本章其余部分让 $\mathbf f$ 在所述正则性条件内保持灵活，转而给源增加结构。

Temporal structure: time-contrastive and permutation-contrastive learning时间结构：时间对比学习与置换对比学习

For linear ICA, temporal structure was an alternative to non-Gaussianity (). For nonlinear ICA it becomes a source of identifiability in its own right. The methods of Hyvärinen and Morioka turn estimation into classification, using a simple fact about logistic regression. Suppose a classifier is trained on equal numbers of samples from two densities $p_1$ and $p_0$ and models the posterior probability of the first class as $1/(1 + e^{-r(\bv)})$. The true posterior is $p_1(\bv)/(p_1(\bv) + p_0(\bv))$, so the optimal regression function is the log-density ratio

对线性 ICA 而言，时间结构是非高斯性之外的另一种选择（）。对非线性 ICA 而言，它本身就成了可辨识性的来源。Hyvärinen 与 Morioka 的方法把估计问题变成分类问题，所依据的是逻辑回归的一个简单事实。设用来自两个密度 $p_1$ 与 $p_0$ 的等量样本训练一个分类器，它把第一类的后验概率建模为 $1/(1 + e^{-r(\bv)})$。真实后验是 $p_1(\bv)/(p_1(\bv) + p_0(\bv))$，所以最优的回归函数就是对数密度比

$$r^*(\bv) = \log p_1(\bv) - \log p_0(\bv).$$

With flexible models and enough data, logistic regression therefore learns a log-density ratio; this is the principle of noise-contrastive estimation (Gutmann & Hyvärinen, 2012). In nonlinear ICA the two densities share the same mixing function, and their ratio turns out to be blind to it.

因此，只要模型足够灵活、数据足够多，逻辑回归学到的就是对数密度比；这正是噪声对比估计的原理（Gutmann & Hyvärinen, 2012）。在非线性 ICA 中，两个密度共享同一个混合函数，而它们的比值恰好对这个混合函数“视而不见”。

Time-contrastive learning时间对比学习

Suppose the sources are nonstationary. The time series is divided into segments $\tau = 1, \dots, K$; within each segment the sources are independent, and their log-densities change from segment to segment through an exponential family,

$$\log p_\tau(s_i) = q_{i,0}(s_i) + \lambda_i(\tau)\,q_i(s_i) - \log Z_i(\tau),$$

where $q_{i,0}$ and $q_i$ are fixed functions, $\lambda_i(\tau)$ is a modulation parameter and $Z_i(\tau)$ a normalizing constant. With $q_{i,0} = 0$ and $q_i(s) = -s^2/2$, for instance, $\lambda_i(\tau)$ is the inverse variance of source $i$ in segment $\tau$: the sources are Gaussian with power that fluctuates over time. $$P(\tau \mid \bx) = \frac{\exp\bigl(\bw_\tau^\top\mathbf h(\bx) + b_\tau\bigr)}{\sum_{\tau'=1}^K \exp\bigl(\bw_{\tau'}^\top\mathbf h(\bx) + b_{\tau'}\bigr)},$$

其中 $\mathbf h\colon \R^n \to \R^n$ 是特征提取器，实践中是一个神经网络，与权重 $\bw_\tau$ 和偏置 $b_\tau$ 一起训练。

Let $\pi_\tau$ be the proportion of samples in segment $\tau$. By Bayes' rule $P(\tau\mid\bx) \propto \pi_\tau\,p_\tau(\bx)$, so equating the log-odds of segment $\tau$ against segment 1 under the classifier and under the truth gives

$$(\bw_\tau - \bw_1)^\top\mathbf h(\bx) + b_\tau - b_1 = \log p_\tau(\bx) - \log p_1(\bx) + \log\frac{\pi_\tau}{\pi_1}.$$

By the change-of-variables formula, with $\bs = \mathbf f^{-1}(\bx)$ and $\mathbf J$ denoting a Jacobian matrix,

由变量替换公式，记 $\bs = \mathbf f^{-1}(\bx)$，$\mathbf J$ 表示 Jacobian 矩阵，则

$$\log p_\tau(\bx) = \sum_{i=1}^n \log p_\tau(s_i) + \log\bigl|\det \mathbf J_{\mathbf f^{-1}}(\bx)\bigr|.$$

$$\log p_\tau(\bx) - \log p_1(\bx) = \sum_{i=1}^n \bigl(\lambda_i(\tau) - \lambda_i(1)\bigr)\,q_i(s_i) - \sum_{i=1}^n \log\frac{Z_i(\tau)}{Z_i(1)}.$$

Stacking the equations for $\tau = 2, \dots, K$ gives $\mathbf L\,\bq(\bs) = \tilde\bW\mathbf h(\bx) + \tilde{\mathbf b}$, where $\tilde\bW$ has rows $(\bw_\tau - \bw_1)^\top$ and $\tilde{\mathbf b}$ collects the constants. Because $\mathbf L$ has full column rank, its pseudo-inverse satisfies $\mathbf L^+\mathbf L = \bI$, and multiplying by $\mathbf L^+$ gives the claim with $\bB = \mathbf L^+\tilde\bW$ and $\mathbf d = \mathbf L^+\tilde{\mathbf b}$. Finally, if $\bB$ were singular, some vector $\mathbf c \neq \bzero$ would satisfy $\mathbf c^\top\bB = \bzero^\top$, and $\mathbf c^\top\bq(\bs) = \mathbf c^\top\mathbf d$ would be almost surely constant within a segment. Hence $\bB$ is invertible.

把 $\tau = 2, \dots, K$ 的方程堆叠起来，得到 $\mathbf L\,\bq(\bs) = \tilde\bW\mathbf h(\bx) + \tilde{\mathbf b}$，其中 $\tilde\bW$ 的各行为 $(\bw_\tau - \bw_1)^\top$，$\tilde{\mathbf b}$ 汇集了各常数项。由于 $\mathbf L$ 列满秩，其伪逆满足 $\mathbf L^+\mathbf L = \bI$，左乘 $\mathbf L^+$ 即得结论，其中 $\bB = \mathbf L^+\tilde\bW$，$\mathbf d = \mathbf L^+\tilde{\mathbf b}$。最后，若 $\bB$ 奇异，则存在向量 $\mathbf c \neq \bzero$ 使 $\mathbf c^\top\bB = \bzero^\top$，于是在一段之内 $\mathbf c^\top\bq(\bs) = \mathbf c^\top\mathbf d$ 几乎必然为常数。这不可能：取 $c_i \neq 0$ 的下标 $i$，则 $q_i(s_i)$ 几乎必然等于其余分量的某个函数，而其余分量与它独立；与自身独立的随机变量几乎必然为常数，矛盾。故 $\bB$ 可逆。

This is a slight generalization of Theorem 1 of Hyvärinen and Morioka (2016), with the same proof. The cancellation of the Jacobian is the heart of the matter: in the likelihood of a single segment, $\log|\det\mathbf J_{\mathbf f^{-1}}|$ is an unknown function that can absorb almost anything, but a ratio of two densities generated by the same mixing function does not contain it. The rank condition on $\mathbf L$ is a sufficient variability requirement: at least $n + 1$ segments, with source distributions that change in sufficiently different ways (). It remains to undo $\bB$. The $q_i(s_i)$ are independent within each segment, but generally not when the segments are pooled, because the pooled density is a mixture of product densities. The natural last step is therefore a linear method that uses the nonstationarity: within segment $\tau$ the covariance matrix of $\mathbf h(\bx)$ equals $\bB^{-1}$ times a diagonal matrix times $\bB^{-\top}$, so joint diagonalization of the segment-wise covariance matrices recovers the $q_i(s_i)$ (), provided no two of them have proportional variance profiles across segments. An ordinary ICA of the pooled features is exact only when the pooled $q_i(s_i)$ are independent and non-Gaussian. Note that $q_i(s_i)$ need not be an invertible function of $s_i$: with $q_i(s) = -s^2/2$ the sign of $s_i$ is lost.

这是 Hyvärinen 与 Morioka（2016）定理 1 的一个小推广，证明完全相同。Jacobian 被消去是问题的关键：在单独一段的似然中，$\log|\det\mathbf J_{\mathbf f^{-1}}|$ 是一个几乎什么都能吸收的未知函数，而由同一混合函数生成的两个密度之比根本不含这一项。关于 $\mathbf L$ 的秩条件是一种充分变化性要求：至少要有 $n + 1$ 段，而且各源分布的变化方式要足够不同（）。剩下的是去掉 $\bB$。各 $q_i(s_i)$ 在每一段内相互独立，但把各段合并后一般并不独立，因为合并后的密度是若干乘积密度的混合。因此最后一步宜采用利用非平稳性的线性方法：在第 $\tau$ 段内，$\mathbf h(\bx)$ 的协方差矩阵等于 $\bB^{-1}$ 乘一个对角矩阵再乘 $\bB^{-\top}$，所以只要没有两个 $q_i(s_i)$ 的方差随段变化的轮廓成比例，对各段协方差矩阵做联合对角化就能恢复各 $q_i(s_i)$（）。只有当合并后的 $q_i(s_i)$ 相互独立且非高斯时，对合并数据做普通 ICA 才是精确的。注意 $q_i(s_i)$ 未必是 $s_i$ 的可逆函数：当 $q_i(s) = -s^2/2$ 时，$s_i$ 的符号就丢失了。

Permutation-contrastive learning置换对比学习

Permutation-contrastive learning (PCL; Hyvärinen & Morioka, 2017) assumes instead that the sources are stationary with temporal dependence. It discriminates pairs of consecutive observations $(\bx(t), \bx(t-1))$ from pairs $(\bx(t), \bx(t^*))$ with a randomly chosen time $t^*$, which have the same marginals but no temporal dependence. Its regression function is a sum of terms $B_i$, each depending only on one learned feature $h_i$ at the two time points. Hyvärinen and Morioka proved that the learned $h_i$ recover the sources up to permutation and componentwise invertible transformations if $\mathbf f$ is a bijection that is twice differentiable with a twice differentiable inverse, the sources are mutually independent, stationary and ergodic processes, and each source is

置换对比学习（permutation-contrastive learning, PCL；Hyvärinen & Morioka, 2017）则假设源是平稳的、但在时间上相互依赖。它区分相邻时刻的观测对 $(\bx(t), \bx(t-1))$ 与随机选取时刻 $t^*$ 构成的观测对 $(\bx(t), \bx(t^*))$；后者的边缘分布相同，但没有时间依赖。它的回归函数是若干项 $B_i$ 之和，每一项只依赖于一个学到的特征 $h_i$ 在两个时刻的取值。Hyvärinen 与 Morioka 证明：若 $\mathbf f$ 是二阶可微且逆映射也二阶可微的双射，各源是相互独立的平稳遍历过程，并且每个源都满足下面两个条件，则学到的 $h_i$ 能在置换与逐分量可逆变换的意义下恢复源：

  • Uniformly dependent: writing $p(a, b)$ for the joint density of $s_i(t)$ and $s_i(t-1)$, the cross-derivative $\partial^2 \log p(a, b)/\partial a\,\partial b$ exists, is continuous and is nonzero everywhere.
  • Not quasi-Gaussian: this cross-derivative is not of the form $c\,\alpha(a)\,\alpha(b)$ for a constant $c$ and a function $\alpha$.
  • 一致依赖：记 $p(a, b)$ 为 $s_i(t)$ 与 $s_i(t-1)$ 的联合密度，交叉导数 $\partial^2 \log p(a, b)/\partial a\,\partial b$ 存在、连续且处处非零。
  • 非拟高斯：这个交叉导数不能写成 $c\,\alpha(a)\,\alpha(b)$ 的形式，其中 $c$ 为常数，$\alpha$ 为某个函数。

A stationary Gaussian autoregressive process has a constant cross-derivative and is therefore quasi-Gaussian. For quasi-Gaussian sources PCL recovers only an invertible linear mixture of transformed sources, which a further linear step must unmix (Hyvärinen & Morioka, 2017).

平稳的高斯自回归过程的交叉导数是常数，因而是拟高斯的。对拟高斯的源，PCL 只能恢复变换后各源的一个可逆线性混合，还需要再做一步线性解混（Hyvärinen & Morioka, 2017）。

Auxiliary variables and generalized contrastive learning辅助变量与广义对比学习

Read “given” literally. Sources can be independent within each value of an auxiliary variable yet dependent after those groups are pooled. Two independent noisy measurements of the same changing group mean share that mean in pooled data. Conditional independence therefore makes a different claim from ordinary marginal independence.

认真理解“给定”。在辅助变量每个取值内部，源可能独立；把这些组混在一起后，却可能相关。对同一个随组变化的均值做两次独立含噪测量，合并数据便会共享这个均值。所以条件独立与普通边缘独立是不同的命题。

TCL and PCL share a structure. In both, an observed variable, the segment label $\tau$ in TCL and the past observation $\bx(t-1)$ in PCL, changes the distribution of the sources without changing the mixing function. Hyvärinen, Sasaki and Turner (2019) made this the definition of the model: the sources are conditionally independent given an observed auxiliary variable $\bu$,

TCL 与 PCL 有共同的结构。两者都有一个观测到的变量（TCL 中是段标号 $\tau$，PCL 中是前一时刻的观测 $\bx(t-1)$），它改变源的分布，却不改变混合函数。Hyvärinen、Sasaki 与 Turner（2019）把这一点直接作为模型的定义：给定一个观测到的辅助变量 $\bu$，各源条件独立，

$$\bx = \mathbf f(\bs), \qquad \log p(\bs \mid \bu) = \sum_{i=1}^n q_i(s_i, \bu),$$

Disentanglement and its limits解耦表示及其局限

Deep representation learning often aims for disentangled representations, in which each coordinate captures one independent factor of variation, such as pose, lighting or identity in images of faces. If the factors are independent and the data are a deterministic invertible function of them, this is exactly nonlinear ICA, and the results of this chapter apply. Locatello et al. (2019) proved that for every factorized density on $\R^d$ with $d > 1$ there is an infinite family of bijections $\mathbf m$ such that $\mathbf m(\bs)$ has the distribution of $\bs$ and every partial derivative $\partial m_i/\partial s_j$ is nonzero almost everywhere: maps like the spiral of , which entangle every output with every factor while leaving the distribution unchanged. They concluded that unsupervised learning of disentangled representations is impossible without inductive biases on both the models and the data. A large experimental study in the same paper, with more than 12,000 trained models on seven data sets, found that well-disentangled models could not be identified reliably without supervision, and that results depended substantially on random seeds and hyperparameters.

深度表示学习常常追求解耦的表示，即每个坐标只刻画一个独立的变化因素，例如人脸图像中的姿态、光照或身份。如果各因素相互独立，而数据是它们的确定性可逆函数，这就恰好是非线性 ICA，本章的结论都适用。Locatello 等（2019）证明：对 $\R^d$（$d > 1$）上任何可分解的密度，都存在无穷多个双射 $\mathbf m$，使 $\mathbf m(\bs)$ 与 $\bs$ 同分布，且每个偏导数 $\partial m_i/\partial s_j$ 几乎处处非零。这正是 中螺旋那样的映射：它让每个输出与每个因素都纠缠在一起，分布却保持不变。他们由此得出结论：若对模型和数据都没有归纳偏置，无监督地学习解耦表示是不可能的。同一篇论文中的大规模实验训练了 12,000 多个模型、涉及七个数据集，发现没有监督就无法可靠地挑出解耦良好的模型，而且结果在相当程度上取决于随机种子与超参数。

Nonlinear ICA theory says which inductive biases suffice: an observed auxiliary variable that modulates the sources (TCL, PCL, GCL, iVAE), or a restricted class of mixing functions (post-nonlinear, conformal). The guarantees have limits. They are asymptotic, assuming infinite data, flexible enough function classes and a global optimum; assumptions such as conditional independence given $\bu$ or sufficient variability can rarely be verified from data; and the sources are recovered only up to permutation and componentwise invertible transformations, so their scale, units and sometimes their sign are lost. Hyvärinen, Khemakhem and Morioka (2023) review the field and its connections to self-supervised learning.

非线性 ICA 理论回答了哪些归纳偏置是足够的：一个调制源分布的观测辅助变量（TCL、PCL、GCL、iVAE），或者一个受限的混合函数类（后非线性或共形映射）。这些保证都有局限。它们是渐近结论，假设数据无穷多、函数类足够灵活、优化达到全局最优；给定 $\bu$ 的条件独立、充分变化性之类的假设，很少能从数据中检验；而且源只能在置换与逐分量可逆变换的意义下恢复，其尺度、单位乃至符号都可能丢失。Hyvärinen、Khemakhem 与 Morioka（2023）综述了这一领域及其与自监督学习的联系。

Designing the auxiliary variable and checking the guarantee辅助变量设计与理论保证的检查

Conditional independence is not marginal independence. For example, $s_1=u+e_1$ and $s_2=u+e_2$, with independent centered $u,e_1,e_2$, are independent conditional on $u$, but $\Cov(s_1,s_2)=\Var(u)$. Testing pooled independence would reject a valid conditional model. Conversely, a classifier that predicts $u$ accurately need not recover separate sources: it can exploit one strongly modulated source while the remaining modulation directions have deficient rank. Inspect the intended modulation mechanism, not just classification accuracy.

条件独立不等于边缘独立。例如，若中心化的 $u,e_1,e_2$ 相互独立，令 $s_1=u+e_1$、$s_2=u+e_2$，则二者给定 $u$ 独立，却满足 $\Cov(s_1,s_2)=\Var(u)$。检验合并数据的独立性会拒绝一个正确的条件模型。反过来，分类器能准确预测 $u$，也不意味着恢复了不同源：它可能只利用一个调制很强的源，而其余调制方向秩不足。因此需要检查调制机制，而不只是分类准确率。

The exact density-ratio assumption in the GCL theorem is substantive: universal function approximators for each $\beta_i$ do not automatically make their structured sum universal. When the sources are marginally dependent, the term $-\log p_{\bs}(\bs)$ need not split over coordinates. One can augment the classifier by an unrestricted $u$-independent term $a(\bx)$, using $r=a(\bx)+\sum_i\beta_i(h_i(\bx),\bu)$. At $\mathbf h=\mathbf f^{-1}$, choose $a(\bx)=-\log p_{\bs}(\mathbf f^{-1}(\bx))$ and $\beta_i=q_i$ to represent the exact ratio. The proof above still works: $a$ cancels when subtracting the equations at $\bu$ and $\bu_0$. This is an explicit extension of the stated classifier, not an assumption that approximation capacity alone supplies the missing term.

GCL 定理中精确表示密度比的假设是实质性的：每个 $\beta_i$ 都使用通用函数逼近器，并不自动使受结构约束的总和通用。若源边缘相关，$-\log p_{\bs}(\bs)$ 未必能按坐标拆开。可向分类器加入不依赖 $u$ 的自由项 $a(\bx)$，使用 $r=a(\bx)+\sum_i\beta_i(h_i(\bx),\bu)$。在 $\mathbf h=\mathbf f^{-1}$ 时，取 $a(\bx)=-\log p_{\bs}(\mathbf f^{-1}(\bx))$、$\beta_i=q_i$ 即可表示精确密度比。上面的证明仍适用：将 $\bu$ 与 $\bu_0$ 处的等式相减时，$a$ 被消去。这是明确扩展分类器，而非假定逼近能力会自动补齐缺少的项。

If $u$ changes the measurement process itself, so that $\bx=\mathbf f(\bs,u)$, the common-Jacobian cancellation no longer follows. Scanner/site labels are therefore not automatically valid auxiliary variables. Split training and evaluation by independent subjects or sessions, preserve dependence when constructing negative pairs, and check whether the same mixing mechanism is plausible across environments. In noisy iVAE, distributional deconvolution identifies model parameters up to the stated equivalence; it does not invert noise in each observed sample. Posterior uncertainty remains even with infinite training data. These are statistical identification results, not proofs that a learned factor is a causal mechanism (Hyvärinen, Sasaki & Turner, 2019; Khemakhem et al., 2020).

若 $u$ 改变测量过程本身，即 $\bx=\mathbf f(\bs,u)$，公共 Jacobian 的抵消便不再成立。因此扫描仪或站点标签不自动成为有效的辅助变量。应按独立被试或扫描划分训练与评估数据，构造负样本对时考虑依赖，并检查不同环境中是否可以假定相同混合机制。在含噪 iVAE 中，分布层面的反卷积使模型参数在所述等价意义下可辨识，并不是消除了每个观测样本中的噪声；即使训练数据无限多，后验不确定性仍然存在。这些是统计辨识结论，不是学到的因子具有因果机制意义的证明（Hyvärinen, Sasaki & Turner, 2019；Khemakhem et al., 2020）。

Key points

本章要点

  • Nonlinear ICA models $\bx = \mathbf f(\bs)$ with an invertible $\mathbf f$. At best the sources are recovered up to permutation and componentwise invertible transformations, so the shape of their marginal distributions carries no information.
  • Without further assumptions the problem is not identifiable: the Darmois construction produces independent components under continuous conditional-distribution assumptions, and measure-preserving maps of $\Ncal(\bzero, \bI)$ yield a continuum of spurious solutions for sources with continuous, strictly increasing CDFs, smooth ones when the source densities are smooth and positive.
  • Restricting the mixing function, as in post-nonlinear mixtures, restores identifiability at the cost of generality.
  • An observed auxiliary variable that modulates the source distributions makes a log-density ratio free of the unknown Jacobian; contrastive learning then recovers the sources under a sufficient-variability condition (TCL, PCL, GCL).
  • The iVAE gives comparable guarantees within a likelihood framework with noise; a VAE with an unconditional Gaussian prior is not identifiable.
  • The impossibility result for unsupervised disentanglement is the same non-identifiability; auxiliary variables and restricted mixing functions are inductive biases that resolve it.
  • 非线性 ICA 的模型是 $\bx = \mathbf f(\bs)$，其中 $\mathbf f$ 可逆。最好的结果也只是在置换与逐分量可逆变换的意义下恢复源，因此源的边缘分布形状不携带任何信息。
  • 不加其他假设时问题不可辨识：Darmois 构造在条件分布连续的假设下能产生独立分量，$\Ncal(\bzero, \bI)$ 的保测映射对 CDF 连续且严格递增的源都能给出一整族伪解；当源密度光滑且为正时，这些伪解也是光滑的。
  • 限制混合函数（例如后非线性混合）可以恢复可辨识性，代价是失去一般性。
  • 若有一个调制源分布的观测辅助变量，对数密度比就不再含未知的 Jacobian；在充分变化性条件下，对比学习能够恢复源（TCL、PCL、GCL）。
  • iVAE 在带噪声的似然框架中给出类似的保证；先验为与条件无关的高斯分布的 VAE 不可辨识。
  • 无监督解耦表示学习的不可能性结论，本质上就是同一种不可辨识性；辅助变量与受限的混合函数都是能消除它的归纳偏置。

Let $\bv\colon \R^n \to \R^n$ be a continuously differentiable bijection whose Jacobian matrix $\mathbf J_{\bv}(\by)$ is invertible for every $\by$ and has at most one nonzero entry in each row. Show that there are a permutation $\sigma$ and strictly monotonic functions $\phi_i$ such that $v_i(\by) = \phi_i(y_{\sigma(i)})$ for all $i$ and $\by$.

补全证明的最后一步。设 $\bv\colon \R^n \to \R^n$ 是连续可微的双射，其 Jacobian 矩阵 $\mathbf J_{\bv}(\by)$ 对每个 $\by$ 都可逆，且每行至多有一个非零元。证明存在置换 $\sigma$ 与严格单调函数 $\phi_i$，使对所有 $i$ 与 $\by$ 都有 $v_i(\by) = \phi_i(y_{\sigma(i)})$。

Fix $\by$. An invertible matrix has no zero row, so each row has exactly one nonzero entry, say in column $\sigma_{\by}(i)$. If two rows had their nonzero entries in the same column, some other column would be zero and the matrix singular; so $\sigma_{\by}$ is a permutation. Next, the entries $\partial v_i/\partial y_j$ are continuous. At a given $\by_0$, the $n$ entries $\partial v_i/\partial y_{\sigma_{\by_0}(i)}$ are nonzero, so they remain nonzero on a neighborhood of $\by_0$; since each row has only one nonzero entry, $\sigma_{\by} = \sigma_{\by_0}$ on that neighborhood. The map $\by \mapsto \sigma_{\by}$ is therefore locally constant on the connected set $\R^n$, hence constant; call it $\sigma$. Then $\partial v_i/\partial y_j = 0$ everywhere for $j \neq \sigma(i)$, so by the mean value theorem $v_i$ does not change when any coordinate other than $y_{\sigma(i)}$ changes, and $v_i(\by) = \phi_i(y_{\sigma(i)})$ for a function $\phi_i$ of one variable. Its derivative $\phi_i' = \partial v_i/\partial y_{\sigma(i)}$ is continuous and never zero, so by the intermediate value theorem it has a constant sign, and $\phi_i$ is strictly monotonic.

固定 $\by$。可逆矩阵没有零行，所以每行恰有一个非零元，设其位于第 $\sigma_{\by}(i)$ 列。若有两行的非零元位于同一列，则另有某一列全为零，矩阵奇异；所以 $\sigma_{\by}$ 是一个置换。其次，各元素 $\partial v_i/\partial y_j$ 连续。在给定的 $\by_0$ 处，$n$ 个元素 $\partial v_i/\partial y_{\sigma_{\by_0}(i)}$ 非零，因而在 $\by_0$ 的某个邻域内保持非零；由于每行只有一个非零元，在该邻域内 $\sigma_{\by} = \sigma_{\by_0}$。于是 $\by \mapsto \sigma_{\by}$ 在连通集 $\R^n$ 上局部恒定，从而恒定，记为 $\sigma$。这样当 $j \neq \sigma(i)$ 时处处有 $\partial v_i/\partial y_j = 0$，由中值定理，改变 $y_{\sigma(i)}$ 以外的任何坐标都不会改变 $v_i$，所以 $v_i(\by) = \phi_i(y_{\sigma(i)})$，其中 $\phi_i$ 是一元函数。它的导数 $\phi_i' = \partial v_i/\partial y_{\sigma(i)}$ 连续且处处非零，由介值定理其符号恒定，故 $\phi_i$ 严格单调。
