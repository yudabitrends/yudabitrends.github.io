15.1 From one subject to many从单个被试到多个被试

Most fMRI studies compare networks between people: patients and controls, young and old, before and after treatment. ICA of each subject separately returns components in arbitrary order, sign and scale (Section 1.3第 1.3 节), and sometimes with different splits of the same network, so the components must be matched across subjects before anything can be compared. Matching by spatial correlation or by clustering is possible but error-prone, especially at higher model orders. Group methods build the correspondence into the model instead. They differ in what they assume to be shared: the maps (temporal concatenation, Section 15.2第 15.2 节); the time courses (spatial concatenation, Svensén, Kruggel & Benali, 2002, which suits experiments in which all subjects follow the same stimulus timing, but not rest); both maps and time courses up to subject-specific loadings (tensor PICA; Beckmann & Smith, 2005); or neither, with corresponding components linked only by statistical dependence (independent vector analysis, Section 15.6第 15.6 节). Calhoun, Liu and Adalı (2009) review these approaches. This chapter develops the ones most used in practice, then turns to what is computed from the components: connectivity between networks and links between imaging modalities.

大多数 fMRI 研究要在人与人之间比较网络：患者与对照、年轻人与老年人、治疗前与治疗后。对每个被试单独做 ICA，得到的成分顺序、符号与尺度都是任意的（Section 1.3第 1.3 节），同一个网络有时还会以不同的方式被拆分，因此在做任何比较之前，必须先把成分在被试之间对应起来。按空间相关或聚类来匹配是可行的，但容易出错，模型阶数较高时尤其如此。组方法则把对应关系直接写进模型。它们的区别在于假设哪些东西是共享的：共享空间图（时间拼接，Section 15.2第 15.2 节）；共享时间过程（空间拼接，Svensén, Kruggel & Benali, 2002，适合所有被试遵循相同刺激时序的实验，不适合静息态）；空间图和时间过程都共享、只差被试特有的载荷（张量 PICA；Beckmann & Smith, 2005）；或者都不共享，相互对应的成分只靠统计依赖联系起来（独立向量分析，Section 15.6第 15.6 节）。Calhoun、Liu 与 Adalı（2009）综述了这些方法。本章先讨论实践中最常用的几种，再转向由成分计算的量：网络之间的连接，以及不同成像模态之间的联系。

15.3 Back-reconstruction反重建

Group maps are only half the answer: comparisons between subjects need each subject's own time courses and maps. Back-reconstruction obtains them by running the reductions backwards. If the group PCA loses little, Y≈G⊤GY=G⊤BS^\bY \approx \bG^\top\bG\bY = \bG^\top\bB\hat\bSY≈G⊤GY=G⊤BS^, and the rows that belong to subject iii give Yi≈Gi⊤BS^\bY_i \approx \bG_i^\top\bB\hat\bSYi​≈Gi⊤​BS^; if the subject PCA loses little, Xi≈Fi⊤Yi\bX_i \approx \bF_i^\top\bY_iXi​≈Fi⊤​Yi​. This suggests the subject time courses (T×nT\times nT×n) and maps (n×Vn\times Vn×V)

组空间图只是答案的一半：被试之间的比较需要每个被试自己的时间过程与空间图。反重建通过把降维步骤倒推回去来得到它们。若组水平 PCA 损失很少，则 Y≈G⊤GY=G⊤BS^\bY \approx \bG^\top\bG\bY = \bG^\top\bB\hat\bSY≈G⊤GY=G⊤BS^，取出属于被试 iii 的那些行，得到 Yi≈Gi⊤BS^\bY_i \approx \bG_i^\top\bB\hat\bSYi​≈Gi⊤​BS^；若被试水平 PCA 损失很少，则 Xi≈Fi⊤Yi\bX_i \approx \bF_i^\top\bY_iXi​≈Fi⊤​Yi​。由此得到被试的时间过程（T×nT\times nT×n）与空间图（n×Vn\times Vn×V）：

This is the back-reconstruction of Calhoun et al. (2001), written in the present notation; Erhardt et al. (2011) call it GICA1. Because Fi⊤\bF_i^\topFi⊤​ has orthonormal columns, Aˇi+=(Gi⊤B)+Fi\check\bA_i^+ = (\bG_i^\top\bB)^+\bF_iAˇi+​=(Gi⊤​B)+Fi​, so Sˇi=Aˇi+Xi\check\bS_i = \check\bA_i^+\bX_iSˇi​=Aˇi+​Xi​: the subject maps are the least-squares regression of the subject's data on the subject's time courses. 15.4 Dual regression双回归

Dual regression (Beckmann et al., 2009; Filippini et al., 2009), called spatio-temporal regression (STR) by Erhardt et al. (2011), skips the PCA bookkeeping and uses only a set of group maps S^\hat\bSS^, from group ICA or from elsewhere, together with the subject's own data. Stage 1 is a spatial regression: each image of subject iii is regressed on the group maps, which gives the subject's time courses. Stage 2 is a temporal regression: each voxel's time series is regressed on these time courses, which gives the subject's maps. import numpy as np

def fastica(Z, rng, iters=200):                       # symmetric FastICA, g = tanh
    U = np.linalg.qr(rng.standard_normal((len(Z), len(Z))))[0]
    for _ in range(iters):
        Y = U @ Z
        U = np.tanh(Y) @ Z.T / Z.shape[1] - np.diag((1 - np.tanh(Y)**2).mean(1)) @ U
        u, _, vt = np.linalg.svd(U); U = u @ vt
    return U

def pca_rows(X, k):                                   # k leading eigenvectors, as rows
    d, E = np.linalg.eigh(X @ X.T / X.shape[1])
    return E[:, ::-1][:, :k].T, d[::-1][:k]

rng = np.random.default_rng(0)
side, T, M, q, n = 30, 100, 6, 5, 3                   # grid, scans, subjects, PCA dims
yy, xx = np.mgrid[0:side, 0:side]
blob = lambda cy, cx, r: np.exp(-((yy - cy)**2 + (xx - cx)**2) / (2 * r**2)).ravel()
Xs, Ss = [], []
for i in range(M):                                    # blobs shifted at random per subject
    S = np.vstack([blob(cy + rng.integers(-4, 5), cx + rng.integers(-4, 5), r)
                   for cy, cx, r in [(8, 8, 3), (20, 22, 4), (8, 22, 3)]])
    A = np.cumsum(rng.standard_normal((T, n)), 0)    # subject-specific time courses
    X = (A - A.mean(0)) / A.std(0) @ S + 0.3 * rng.standard_normal((T, side**2))
    Xs.append(X - X.mean(1, keepdims=True)); Ss.append(S)

Fs = [pca_rows(X, q)[0] for X in Xs]                  # subject PCA: q x T each
Y = np.vstack([F @ X for F, X in zip(Fs, Xs)])        # temporal concatenation: Mq x V
G, lam = pca_rows(Y, n)                               # group PCA: n x Mq
Z = np.diag(lam ** -0.5) @ G @ Y
U = fastica(Z, rng)
S_g, B = U @ Z, np.diag(lam ** 0.5) @ U.T             # group maps; G Y = B S_g

def match(S_est, S_true):                             # mean |corr| of best-matching rows
    return np.abs(np.corrcoef(S_est, S_true)[:n, n:]).max(0).mean()
r0, r1, r2 = [], [], []
for X, F, Gi, S in zip(Xs, Fs, np.split(G, M, axis=1), Ss):
    S_1 = np.linalg.pinv(Gi.T @ B) @ F @ X            # GICA1 back-reconstruction
    A_dr = X @ np.linalg.pinv(S_g)                    # dual regression, stage 1
    S_dr = np.linalg.pinv(A_dr) @ X                   # dual regression, stage 2
    r0.append(match(S_g, S)); r1.append(match(S_1, S)); r2.append(match(S_dr, S))
print(Y.shape, S_g.shape)
print(np.round([np.mean(r0), np.mean(r1), np.mean(r2)], 3))

15.5 Spatially constrained ICA and NeuroMark空间约束 ICA 与 NeuroMark

Back-reconstruction and dual regression obtain subject components by regression and never ask them to be independent. Spatially constrained ICA instead runs ICA on each subject's data and uses reference maps to guide it. In the semi-blind spatial ICA of Lin et al. (2010), each component maximizes a non-Gaussianity contrast subject to a constraint that keeps it close to a spatial reference, such as a mask defined by an atlas. In group-information-guided ICA (GIG-ICA; Du & Fan, 2013), the references are the group maps, and each subject component is found by a multi-objective optimization that balances its independence against its similarity to the corresponding group component. Key points

本章要点

  • Group ICA by temporal concatenation assumes common maps and subject-specific time courses; a two-stage PCA, first per subject and then of the stacked reduced data, makes the MT×VMT\times VMT×V problem tractable.
  • Back-reconstruction (GICA1) inverts the reductions; dual regression regresses each subject's data on the group maps and then on the resulting time courses. Both have closed forms. Their time courses differ only by the regression, on the group maps, of the part of the subject's data that the subject-level PCA discards, whether or not the reductions are whitened; if that PCA discards nothing, the time courses coincide, and so do the maps unless the subject-level reduction is whitened.
  • Without variance normalization, dual-regression maps equal the group maps plus a correction built from the part of the data outside the span of the group maps; with it, they also reflect network amplitude.
  • Spatially constrained ICA (GIG-ICA, NeuroMark) estimates each subject's components by ICA guided by reference maps, which fixes their order and meaning across subjects and studies.
  • IVA links data sets through dependence within source component vectors; the within-SCV mutual information aligns the components and, with second-order statistics, can separate Gaussian sources whose cross-dataset correlations differ.
  • FNC and dynamic FNC analyse correlations among component time courses; joint and parallel ICA link imaging modalities through subject loadings.
  • 时间拼接的组 ICA 假设空间图共同、时间过程因被试而异；两步 PCA（先对每个被试，再对堆叠后的降维数据）使 MT×VMT\times VMT×V 规模的问题变得可行。
  • 反重建（GICA1）把降维步骤倒推回去；双回归先把每个被试的数据对组空间图回归，再对所得时间过程回归。两者都有闭式解。无论降维是否白化，它们的时间过程之差都只是被试水平 PCA 所舍弃的那部分数据对组空间图的回归；若该 PCA 不舍弃任何数据，则时间过程一致，而且只要被试水平的降维不做白化，空间图也一致。
  • 不做方差归一化时，双回归的空间图等于组空间图加上一个修正项，修正项来自数据中落在组空间图张成空间之外的部分；做方差归一化后，空间图还反映网络的幅度。
  • 空间约束 ICA（GIG-ICA、NeuroMark）在参考图引导下对每个被试做 ICA，使成分的顺序与含义在被试之间、研究之间保持一致。
  • IVA 通过源成分向量内部的依赖把各数据集联系起来；SCV 内部的互信息把成分对齐，而且只用二阶统计量就能分离跨数据集相关结构不同的高斯源。
  • FNC 与动态 FNC 分析成分时间过程之间的相关；联合 ICA 与并行 ICA 通过被试载荷把不同成像模态联系起来。
